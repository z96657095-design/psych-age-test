测测你的心理年龄几岁

一共10题，凭第一感觉选择
1. 周末有空，你更愿意？
A 出门逛街、聚会热闹一下
B 在家安安静静躺着刷手机
C 看书、做点自己喜欢的事
2. 遇到不顺心的事，你通常？
A 忍不住发脾气，情绪写脸上
B 自己消化，不想多说
C 冷静分析，想办法解决
3. 对于网红新梗、新鲜事物
A 很感兴趣，主动去了解
B 随缘，刷到就看看
C 不太感兴趣，觉得麻烦
4. 做决定的时候，你？
A 凭感觉，冲动选择
B 纠结很久，容易犹豫
C 权衡利弊，快速定下来
5. 和别人产生矛盾，你会？
A 当场争辩，争对错
B 冷处理，不想吵架
C 好好沟通，求同存异
6. 你对未来的想法？
A 走一步看一步，开心最重要
B 偶尔焦虑，不太确定
C 有清晰规划，稳步往前走
7. 别人评价你，你会？
A 很在意，容易被影响心情
B 听一听，心里想想
C 不太在意，清楚自己是什么样
8. 花钱的时候，你？
A 喜欢就买，及时行乐
B 偶尔冲动，大部分时候克制
C 理性消费，做好储蓄
9. 你更相信？
A 直觉、缘分和感觉
B 一半感性一半理性
C 现实和逻辑
10. 累的时候，你希望？
A 找人陪伴倾诉
B 自己安静待一会
C 调整状态，尽快恢复

免责声明：本测试仅为趣味娱乐参考，不具备专业心理评估效力，不能作为心理诊断依据。
